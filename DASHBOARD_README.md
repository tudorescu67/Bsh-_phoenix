# Phoenix Bot Dashboard

Dashboard modern pentru botul Discord Phoenix.

## Structură proiect

```
├── backend/       # Server Express + API
├── frontend/      # React + Vite
├── commands/      # Comenzi bot Discord
├── events/        # Evenimente bot Discord
└── index.js       # Bot Discord principal
```

## Instalare

### 1. Backend
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```

## Rulare

1. Rulează backend-ul pe port 5000
2. Rulează frontend-ul pe port 3000
3. Accesează http://localhost:3000

## Funcționalități

- 🎵 Muzică - Player și coadă muzicală
- 🎮 Jocuri - Gestionare jocuri
- 💰 Economie - Sistem de bani virtual
- 🏆 Ranks - Leaderboard și nivele
- 🛡️ Moderare - Acțiuni de moderare
- ⚙️ Setări - Configurare bot
